# TON Jetton Receiver Contract

## Overview
Legitimate smart contract for receiving and managing Jetton (fungible) tokens on TON Blockchain.

## Contract: JettonReceiver
- **Language**: Tact
- **Standard**: TEP-74 (Jetton standard)

## Features
1. **Receive Jetton tokens** - Accepts any JettonTransferNotification deposits
2. **Track deposits** - Maintains total received and deposit count
3. **Owner withdrawals** - Owner can withdraw jettons or TON
4. **Transparent** - All operations visible on-chain

## Architecture
```
User Wallet → Jetton Transfer → JettonReceiver Contract
                                     ↓
                              Stores deposit info
                                     ↓
                              Owner can withdraw
```

## File Structure
```
contracts/

scripts/
  deploy.ts               - Deployment script
  getBalance.ts           - Read contract state
  sendJetton.ts           - Helper for transfers
wrappers/
  (generated by Tact compiler)
tests/
  (test suite)
```

## Jetton Standard (TEP-74)
The contract handles:
- `JettonTransferNotification` (op: 0x7362d09c) - Receiving tokens
- `JettonTransfer` (op: 0x0f8a7ea5) - Sending tokens
- `JettonBurn` (op: 0x595f07bc) - Burning tokens
