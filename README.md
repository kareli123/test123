# TON Jetton Project

Legitimate open-source project for interacting with Jetton (fungible) tokens on the TON Blockchain.

## Features

- **Jetton Token Deposits** - Receive and track Jetton token transfers
- **Secure Withdrawals** - Owner-only withdrawal mechanism
- **Transparent Operations** - All logic is open source and verifiable
- **TON Connect Integration** - Connect with TonKeeper and other wallets
- **TEP-74 Compliant** - Follows official Jetton standard

## Smart Contract

### JettonReceiver

The contract accepts Jetton token deposits and allows the owner to:
- View total received amount and deposit count
- Withdraw Jetton tokens
- Withdraw TON balance

### Security
- Only the deployer (owner) can withdraw funds
- No hidden fees or unexpected transfers
- All operations emit events for transparency

## Quick Start

### Install dependencies
```bash
npm install
```

### Compile contract
```bash
npm run build
```

### Run tests
```bash
npm test
```

### Deploy
```bash
npx blueprint run deploy
```

## Frontend

The frontend demonstrates TON Connect wallet integration and Jetton token interactions.

### Setup
1. Update `config.js` with your deployed contract address
2. Update `tonconnect-manifest.json` with your app metadata
3. Host files on GitHub Pages or any static host

## Jetton Standard (TEP-74)

This project implements the official TON Jetton standard:
- `op::transfer = 0xf8a7ea5`
- `op::transfer_notification = 0x7362d09c`
- `op::burn = 0x595f07bc`
